# 周总结索引

目前没有已确认周次的周总结。不要从当前日期、指南文件名或日记日期推算课程周次，也不要创建占位的 `week-XX.md` 冒充实际周记录。

确认周次及日期范围后，复制 [周总结模板](../templates/weekly.md) 为 `week-NN.md`，同步创建英文同路径文件，并在这里加入日期、周次、记录 ID、状态与链接。一个组每周一条逻辑记录；两种语言不算两次活动。

10 月 28 日的记录是 11 月 3 日补记，周次待确认。导师反馈、个人反思、看板截图和正式提交状态只根据实际材料填写。
