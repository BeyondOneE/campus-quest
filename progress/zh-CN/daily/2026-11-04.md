## CQ-20261104-001 · 不滚动的分屏界面、密码规则与流程说明更正

### 目标与结果

用户审阅 Codex 的交接内容后提出三点：CQ-20261103-009 的流程只是暂定用于测试，不是最终设计；15 位密码不适合面向学生的小游戏，应可随意设置；现有页面交互杂乱，游戏不应设计成滚动页面。

- 已更正项目状态、交接说明和开工指令中“用户已认可交互逻辑”的说法。CQ-20261103-009 的原记录保留，以本条为准。
- 密码改为 1–128 个字符，空密码和超长密码仍被拒绝。用户名规则、登录限流和 scrypt 哈希未变。用户决定不设强度要求；弱密码的账号更容易被猜中，这是已接受的取舍。
- `/treasure-lab/` 重做为入口、外勤、相机三个全屏界面，随会话状态切换，页面本身不滚动。每个状态只提供一个主要操作；房间名单、账号、移动宝藏、切换房间、现场备注和硬件诊断收进底部抽屉。

### 决策、修改与关联

- 修改 `public/treasure-lab/index.html`、`style.css`、`app.js`，未新增静态文件，因此无需改后端白名单或 CSP。定位、相机、后台清理和迟到流取消的逻辑保留，领取门槛和定位参数未变。
- 距离环只表示离开 / 返回的进度，不显示方向，因为后端不下发宝藏坐标，不应暗示存在方向信息。
- 修改 `server/store.mjs` 的密码校验，并把找不到房间的提示改为 “Room not found”。按用户授权由 Claude 直接修改，Codex 未参与本次改动。
- 重新生成 `docs/frontend-dom-contract.json`（88 个带 ID 的元素），同步接口、现场步骤和交接文档。部分控件 ID 已变化，例如 `create-room` / `join-room` 改为 `show-create`、`show-join`、`entry-submit`。
- 流程本身未重新设计：放置 → 离开 → 返回 → 领取由后端规则决定，界面只改呈现方式。最终玩法待用户决定。

## CQ-20261104-002 · 视觉与动效重做

### 目标与结果

- 待解决的问题：用户表示当前交互满意，但课程项目由非专业人士评分，希望提高视觉水平；现有设计缺少惊艳感，界面没有动画，操作后是生硬切换。该反馈未说明观察环境，不作为 iPhone Safari 验收。
- 实际完成：重做 `/treasure-lab/` 视觉并加入全程动效；交互结构、文案逻辑和后端规则未改。未完成：真机效果与性能尚未检查。

### 决策、修改与关联

- 核心概念：一局就是一夜。天空随进度从黄昏（藏宝）到深夜（离开）、黎明前（返回）、清晨（可领取）、日出（已领取），月落日升，校园剪影灯光渐灭。校园剪影为通用插画，不代表真实校区建筑。
- 过渡：退出元素用仅作装饰的副本播放退场动画，真实状态与 `hidden` 仍同步切换，因此测试与无障碍语义不变。相机以光圈式展开，抽屉上下滑动，布局变化平滑移动，距离数字滚动变化。
- 奖励时刻：只有本局向前推进时才放粒子，恢复页面或换房间不放。领取时全屏闪光、宝箱开盖、金币与星光喷出。距离环的脉冲随进度加快，但不表示方向：后端不向页面发送宝藏坐标。
- 遵守 `prefers-reduced-motion`；不支持的浏览器能力直接跳过。未新增静态文件与外部资源，后端白名单和 CSP 未改，后端无需重启。
- 修改 `public/treasure-lab/index.html`、`style.css`、`app.js`，重新生成 `docs/frontend-dom-contract.json`。提交前没有实现提交哈希。

## CQ-20261104-003 · 菜单抽动修复与画面精简

### 目标与结果

- 待解决的问题：用户反馈打开菜单时整个页面抽动一下；对动效和字体满意，但认为画面过于花哨、稍显杂乱。该反馈未说明观察设备，不作为 iPhone Safari 验收。
- 实际完成：修复抽动根因并精简装饰。切换动效、领取仪式和字体保留。未完成：用户 iPhone 上的结果尚未确认。

### 决策、修改与关联

- 抽动根因：抽屉仍在屏幕下方动画时被聚焦，浏览器为显示它而滚动 `.app` 容器。改为 `focus({ preventScroll: true })`，容器改用 `overflow: clip`（旧浏览器回退为 `hidden`），抽屉滑入去掉回弹，避免露出底部。
- 精简原则：静止时只留一个视觉焦点，连续循环的装饰让位给操作后才出现的动效。天空随进度变化的概念保留，但降低饱和度。
- 移除：入口的光芒和闪星、距离环刻度、按钮循环扫光、状态点和进度点的循环闪烁、相机光芒、校园窗灯闪烁和树木。
- 减弱：飘尘只留入口且数量减少，星星变少，月亮、太阳光晕和金色发光变小，宝箱变小，定位读数从两个卡片改为一行小字。
- 修改 `public/treasure-lab/index.html`、`style.css`、`app.js`，`tests/treasure-lab.test.mjs` 增加回归测试。元素 ID 未变，DOM 契约无需更新。提交前没有实现提交哈希。
