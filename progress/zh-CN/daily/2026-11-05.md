## CQ-20261105-001 · 运动传感器用于近场领取的可行性

### 目标与结果

用户反馈最后寻宝阶段的 GPS 精度不足，提出接近后切换手机陀螺仪 / 加速度计。源码确认现设计仍要求报告 GPS 距离在 3 米内、绝对罗盘有效以及 1200 ms 瞄准停留。本次建议未改变这些规则或产品代码。

### 决策、变化与引用

陀螺仪适合短时相对转动，加速度计提供运动 / 重力相关信息；纯惯性位移会累积误差，也不能消除切换起点的 GPS 偏差。建议验证：GPS 判断粗略接近并授予资格，进入短时本地遭遇后固定虚拟目标方向，用相对姿态搜索 / 对准，不把手机加速度积分当成精确步行距离。粗范围确认离开、超时和后台返回需要明确重置规则。候选 10–15 米遭遇范围仅供讨论，未取代用户已有 3 米设置。若要求多人找到精确同一物理点，还需审核的视觉标记等外部参照；视觉惯性跟踪本身也不能解决错误的地理锚点。

核实的资料：[W3C 姿态与运动规范](https://www.w3.org/TR/orientation-event/)、[剑桥惯性导航原理与误差分析](https://www.cl.cam.ac.uk/techreports/UCAM-CL-TR-696.pdf)、[Apple 视觉惯性世界跟踪](https://developer.apple.com/documentation/ARKit/managing-session-life-cycle-and-tracking-quality)。旧剑桥报告只用于解释误差机制，未将其数值当成当前手机精度预测；Apple 原生框架只作概念参考，不代表当前 Safari 网页具备该能力。

### 验证与证据

读取 `public/treasure-lab/model.js`、`ar.js`、`app.js` 及 `server/store.mjs`，查阅一手资料。本次没有新测试 / 构建、传感器采集、模型请求、部署或真机验收；检查双语配对、相对链接及空白。保留既有未提交 AI 修复。

### 人类贡献与 AI 使用

用户指出玩法问题并提出传感器方案；Codex 检查实现、分析可行性、提出有限验证建议并编写双语记录。未推断其他成员工作、工时或个人反思。

### 困难、支持与结果

待确定：附近的虚拟遭遇，还是寻找精确物理点。相对传感器可用性、短时漂移及交互表现需真实 iPhone Safari 验证；本次没有新权限申请或外部求助。

### 反思与下一步

先确定近场交互及资格 / 重置规则，再单独验证传感器表现，不提前承诺精度。建议参数及玩法变更尚未批准。

## CQ-20261105-002 · 实现锁定近场转动搜索

用户批准附近虚拟遭遇方案，要求先做验证版，取代最后 GPS 3 米领取门槛。默认 3 米仅保留为测试离开门槛。实现 15 米中心距离稳定进入（至少两条新鲜不同时间位置跨 2 秒，报告精度不超过 20 米）、90 秒后端遭遇、45° 本地目标偏角及既有 1200 ms 瞄准停留。GPS 漂移、变差、过期及暂时丢失不再打断已锁定搜索。粗范围退出需至少两条位置跨 3 秒，距离减报告精度超过 35 米；长位置间隔会重置退出观察。主动停止、关相机 / 采集结束、后台、身份 / 房间 / 轮次变化、到期及后端重启释放遭遇；相机授权失败保留锁定供重试。

在 `ar.js` 新增 `LocalSearchPose`：按设备轴对陀螺仪角速度进行四元数积分，由重力初始化倾斜，不积分加速度为位置，也不依赖磁北。浏览器相对姿态回退忽略罗盘航向 / 精度并标记对应来源，不宣称等同于纯原始陀螺仪融合；原始陀螺仪事件间隔超过 500 ms 会停止该校准坐标系。运动与姿态权限均在相机点击事件内、等待采集前发起。前端每次遭遇只校准一次，投影固定方向、显示本地搜索倒计时，保留聊天 / 新鲜视频门槛，并在生命周期变化后释放监听及迟到工作。

后端继续持有房间 / 场次权限和领取凭据。新增 `nearField` 状态、`guidance.frame`、每次遭遇不透明 ID、校准坐标系 / 来源绑定及按收到时间验证停留。既有 aim / stop 路由支持匹配 ID 的遭遇取消和暂时 GPS 失效；默认 stop 仍释放全部资格。绝对罗盘、旧 / 错误遭遇及变更校准样本不能解锁本地 Claim。未新增路由、数据表、相机上传或持久移动历史。滑条改为 Departure distance；新增双语 [近场契约 / 测试步骤](../../../docs/near-field-search.md)，覆盖旧 3 米领取描述，并从接口 / 走测 / 交接 / 状态文档链接。

验证：90/90 项自动测试及构建通过；七项新增近场测试覆盖 3 米外进入、漂移 / 精度变差、GPS 过期 / 丢失后领取、粗范围退出 / 到期、坐标系隔离、相对投影、四元数积分及完整运动事件界面路径。更新既有样本以反映获准玩法 / 来源变化，包含拒绝重试、视频过期、后台和迟到权限。隔离真实 HTTP 验证 12 米锁定、GPS 丢失后领取、幂等凭据、玩家隔离及无坐标状态包。输入是内存中的合成样本，不代表 iPhone 现场验收。依赖 / 锁文件未变，无须重新安装，保留既有原型体积警告。
