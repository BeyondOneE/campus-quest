# 仓库规范

[English](repository-guidelines.en.md) · 生效日期：2026-11-03 · 时区：Asia/Shanghai

## 文档与语言

1. 新增或更新的规范、进度、模板、周总结和证据说明必须分别保存中文与英文版本，并在同一提交中同步更新。两份记录使用相同 ID、日期、数字、提交引用、状态和证据范围；事实修正同时修改两份。
2. `progress/zh-CN/` 和 `progress/en/` 使用相同相对路径；不要把两种正文混排成一份记录。保留对照链接。
3. 根目录 `README.md` / `README.zh-CN.md`、`AGENTS.md` / `AGENTS.zh-CN.md` 分别对应英文 / 中文。现有中文 `docs/*.md` 的英文文件使用 `.en.md` 后缀。本规范自己的文件为 `.zh-CN.md` / `.en.md`。
4. 原始交接资料、外部文档、代码、命令、JSON 和截图等保留原样，不为凑双语复制或改写原件；另写双语说明。`docs/archive/` 是历史来源，保持不变。该规则不要求现在扩展产品界面的语言或浏览器范围。

## 日常更新

- 每次完成有实质意义的代码修改、测试、用户反馈分析或项目决策，在当天日记中新增一条记录；仅浏览资料或没有新结论的重复检查不必另记。
- 开始工作时阅读本规范、当前项目状态和最近的日记；结束前更新双语日记、索引以及确有变化的项目状态。实施和记录尽量同一提交；提交完成后再补关联 hash 时可用单独文档提交，不编造自身尚未存在的 hash。
- 一天一份文件，以 `YYYY-MM-DD.md` 命名；一天多项工作使用独立 ID，如 `CQ-20261103-001`。ID 发布后不复用或改号。
- 日记记录目标、结果、理由、涉及文件 / 实现提交、验证方法和结果、证据限制、人员与 AI 分工、阻塞和下一步。使用 [双语模板](../progress/zh-CN/templates/daily.md)。
- 事件日期与实际编写日期分开。补记标注来源和补记日期，不修改 Git 日期，不把缺失的历史写成现场记录。未知的课程周次、工时或成员信息写“待确认”。

## 每周记录与课程提交

- 周总结以课程 Form 1 为结构，汇总已存在的日记和证据，每组每周一条逻辑记录，提供中英文两个文件。周次必须由用户或课程日历确认后才能命名 `week-NN.md`。
- 保留看板链接、日期范围、状态截图、完成内容、挑战、求助及结果、成员个人反思、证据上传状态和正式提交凭据。
- 沿用课程实际看板，不因建立仓库日志自动创建另一套看板。看板移动历史与截图、Git、周记录分别保留并互相引用。提交数量不能单独证明个人贡献。
- 每位成员的反思由本人提供或确认；AI 可协助整理和翻译，不冒写个人经历、不代签名。真实姓名、学号、签名如需正式提交，放在受控提交副本，默认不进入 Git。
- 仓库保存材料不等于课程平台已提交。状态区分草稿、已确认、已提交和有回执；没有凭据不得写“已提交”。周总结由用户决定何时汇总，不设置未经请求的定时任务。

## 证据与隐私

- 证据编号如 `E-20261028-001`。双语说明引用同一原件，登记来源、事件时间、留存位置、SHA256（存在可校验文件时）、支持的结论与限制。
- 小型脱敏附件放 `progress/evidence/YYYY-MM-DD/`。机器可读索引共享一份；语言说明分别放在两个语言目录。JSON 字段名、ID 和哈希不翻译。
- 原始手机报告、精确位置、序列号、UDID、密钥、私人通信、签名和学号留在被忽略的本地位置或受控外部存储。大型视频留在外部存储，记录受控位置、hash 和说明；不得写入带访问令牌的链接。
- 截图说明注明浏览器、设备和验证层级；桌面截图不能替代 iPhone 实测。文件已丢失就标注不可用，不重制一张截图冒充历史证据。
- 区分自动化模拟、桌面检查、真实手机实测、系统报告值和用户主观观察。相机及传感器可用不等于空间 AR 已完成；Brave 的结果不能登记为 Safari 通过。

## 验证、提交与协作

- 保留已有脏改动和原始基线。代码变更执行适用的 `npm test`、`npm run build`；纯文档变更检查双语配对、相对链接、事实一致性和 `git diff --check`。
- 提交前确认未纳入私密原件，确认两个语言版本都已更新。原始日志不为了留痕而强制加入 Git。
- 使用简洁、可核实的表述，披露 AI 执行的分析、代码、文档和翻译，以及用户做出的决策、真机测试和确认。不得把 agent 的 Git 提交自动算作某位成员独立完成。
- 不虚构导师交流、看板活动、用户数、测试、工时或学校提交。相应字段没有来源就保持待确认。

课程条款及来源页码见 [课程要求映射](../progress/zh-CN/course-requirements.md)。
