# 近场搜索验证版

[English](near-field-search.en.md) · 2026-11-05 · CQ-20261105-002

右上角房间菜单提供 **Outdoor** 和 **Indoor**。切换会开启新的房间轮次。[RoNIN 与模式切换](indoor-demo.md)

用户批准 GPS 接近后锁定、通过转动手机搜索的相机玩法，取代最后必须 GPS 在 3 米内才能领取的门槛。手动放置仍是测试工具；这是附近的虚拟遭遇，没有测量过的物理锚点，也不通过惯性推算步行距离。

## 在 iPhone Safari 上试用

1. 刷新可信局域网 `/treasure-lab/` 页面，建房或加入房间并开启定位，由房主放置。默认离开距离为 3 米。房主可在放置前从 **Menu → Test tools** 调整。
2. 走出离开边界后接近：至少两条不同时间的新鲜位置、跨越 2 秒且距离在 15 米内，锁定近场遭遇。进入时报告精度仍须不超过 20 米，使用中心距离判断，不代表测得实际 15 米精度。
3. 打开 AR、允许相机 / 运动权限。先竖直拿稳手机初始化，再转动搜索。宝箱在新校准的本地坐标系中初始位于右侧 45 度；跟随箭头转动后进入画面，转开会离开画面，不代表共享的真实地面点。
4. 将相机对向宝箱，在 18° 的容差内保持至少 700 ms，等进度环填满。点亮起的 **Claim treasure**，等待领取结果。需要实时视频及不同时间的新鲜姿态。打开聊天会清除瞄准，关掉聊天后重新对准再领取。
5. 锁定后，GPS 漂移、精度变差、过期或暂时丢失都不会撤销此次遭遇，倒计时为 90 秒。连续至少两条位置、跨 3 秒且“距离减报告精度”超过 35 米，才确认明显离开并取消。主动停止定位、关闭 / 结束相机、切后台、身份 / 房间 / 轮次变化及后端重启会释放遭遇；相机权限失败保留资格供重试。到期 / 取消后需新的稳定近场位置重新锁定，旧响应不能延长原截止时间。

运动权限拒绝 / 中断时重试授权，或关相机、待区域重新锁定后再打开校准。原始陀螺仪事件间隔超过 500 ms 会停止该坐标系，不凭空补算漏掉的转动。漂移、手机轴 / 横竖屏以及实际现场精度仍须用户的 iPhone Safari 测试。

## 传感器与后端控制

优先使用 `devicemotion.rotationRate`，按设备坐标轴进行四元数积分；`accelerationIncludingGravity` 初始化倾斜，不积分为位置。本地坐标系不使用磁北航向。运动 API / 权限不可用但姿态权限可用时，以浏览器 alpha / beta / gamma 和初始朝向建立相对坐标，忽略 `webkitCompassHeading` / 精度；这是浏览器融合姿态，不承诺等同于原始陀螺仪。远处接近指引仍使用绝对方向。

后端持有遭遇资格、不透明 ID、期限、目标偏角及停留验证。`state.nearField` 为 null 或 `{ id, expiresInMs, radius: 15, exitRadius: 35 }`；近场 `guidance` 含 `frame: local`、`encounterId`、`bearingDegrees: 45`，远处为 `frame: earth`。锁定时 `state.expiresInMs` 使用遭遇期限，否则使用 GPS 时效；本地角度不等于宝藏地理方位。

沿用既有认证 / CSRF / 房间 / 轮次路由：

- `POST /api/aim`：原姿态样本增加 `source: local-gyro | relative-orientation`、`encounterId` 和稳定 `frameId`。后端绑定首个有效校准坐标系 / 来源；不同 / 旧坐标系、错误遭遇及绝对罗盘样本不能解锁本地领取。`sample: null` 只清除瞄准。
- 释放对应遭遇：`POST /api/aim`，发送 `{ roomCode, treasureId, sample: null, cancelEncounter: true, encounterId }`；迟到的其他 ID 取消请求不会释放当前遭遇。
- `POST /api/location/stop` 携带 `{ roomCode, transient: true }` 会使 GPS 失效、保留已锁定遭遇；默认主动 stop 会释放。没有新增路由或持久表。
- `POST /api/collect` 继续检查实时相机状态、后端停留及每人每轮领取凭据，不再检查最后 3 米边界。手机自报姿态 / 相机状态仍是实验输入，不是防作弊证明。

不上传相机帧、原始加速度 / 陀螺仪速率或推算步行路径，只通过已有 aim 路由发送有限瞄准姿态 / 坐标系元数据。保留账号、存储点位、领取结果、私密 Key 和开发 CA。验证见 [当日记录](../progress/zh-CN/daily/2026-11-05.md)，自动样本不代表真机验收。
