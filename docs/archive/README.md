# XJTLU AR Campus Quest

基于用户提供的 Visily 六页 React 导出包整合而成，保留原有界面和素材。

## 打开方式

- 继续开发：在本目录运行 `npm ci`，然后 `npm run dev`，访问终端显示的本机网址。
- 构建部署：运行 `npm run build`，将 `dist` 目录放到静态网站服务器。默认部署到网站根目录。

## 已实现

组队大厅 → 路线选择 → AR 探索 → 收集线索 → 合作解谜 → 成绩页。

支持房间码格式校验与演示房间切换、复制房间码、昵称编辑、三条路线选择、难度筛选、模拟扫描、收集解锁、答案校验、线索提示、计时、按路线计分、复制成绩、返回、重新开始，以及本机进度保存。支持手机窄屏缩放和桌面旅程侧栏。

正确答案为 ACTION。请先收集线索，再进入解谜。

## 范围说明

这是完整可点击的前端演示。房间成员、投票、AR/GPS、语音、排行榜、徽章和 AI 提示均为模拟或预设内容；没有服务器、真实账号验证、跨设备多人同步、摄像头识别、麦克风录音或 AI 模型服务。三条路线采用同一套示例线索，分值不同。浏览器会将演示进度保存在当前设备；清除网站数据会清除进度。

界面里的学生 ID、时间栏和排行榜人数为原设计的示例数据。

## 文件结构

- `src/App.tsx`：流程、状态、校验、设置和提示弹窗。
- `src/screens/`：六个 Visily 页面，已接入交互。
- `src/style.css`：响应式布局和补充样式。
- `public/assets/`：按页面分组的原始素材，避免同名图片互相覆盖。
