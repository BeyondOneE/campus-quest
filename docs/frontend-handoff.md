## 产品与首轮交付

Campus Quest 是手机网页校园寻宝。真实手机定位决定资格，解锁后相机画面显示可收集宝藏。本版没有道路对齐、空间跟踪、地面锚定或路线导航。

目标是用户的 iPhone Safari。所有产品界面直接使用英文，包括标签、错误、等待状态、指引与无障碍文字；维护文档仍分别保存中英两份。

首轮前端应完整覆盖真实流程：

1. 恢复登录，或注册 / 登录 / 以访客继续。
2. 创建房间或用八位码加入，显示当前玩家、房间码、房主权限与名单。
3. 用户主动开启定位，事先说明坐标发给电脑、视频留在手机。
4. 房主用新鲜准确位置放置共享宝藏；所有玩家先离开范围，再返回解锁。
5. 解锁后主动打开后置相机，观察到真实画面更新后才显示可收集宝箱。
6. 服务端确认领取后显示凭据 / 已领取状态，再释放相机。
7. 保留可访问的现场备注、不自动含坐标的导出与硬件诊断入口，作为次要功能。

页面拆分、导航、字体、颜色、间距、图标、宝藏插画和动效由 Claude 设计。地图、定时刷新、成绩、聊天、AI 提示和密码找回尚无后端接口，不应做成貌似已经可用。宝藏自身可以绘制，实时相机背景与定位必须来自真实设备。

## 后端与显示状态

产品权威状态来自 `RemoteTreasureSession`，不能新建本地 `TreasureSession` 作为游戏状态。适配器不管理硬件、DOM 或订阅通知，这些由控制器承担。完整方法 / 响应契约与原生 JavaScript 示例见 [后端接口](backend-api.md)。

| 界面情况 | 显示 / 操作要求 |
| --- | --- |
| 恢复身份 / 请求等待 | 显示进度，阻止重复提交，等待完成后再进入成功界面 |
| 未登录 / 访客 | 提供账号入口和临时访客房间，昵称不验证身份 |
| 已登录但无当前房间 | 显示账号 / 房间选项，不将 `ROOM_REQUIRED` 当成密码错误 |
| 有效访客房间内注册 | 保留玩家 ID、房主权限和凭据，注册前说明关联行为 |
| 登录 / 换设备 | 恢复账号成员，不自动合并无关访客，也不重启硬件 |
| 房主 / 参与者 | `player.role` 为 `owner` 或 `guest`，后者是房间权限角色，已登录账号也可能取该值；只有房主可放置 / 重新放置 |
| 断网 / 会话过期 | 显示恢复或登录入口，禁止领取，不生成本地成功进度 |
| 新宝藏轮次 / 切房 | 丢弃旧资格，重新读取状态，必要时手动重启定位 |
| 已领取 | 显示服务端凭据；重复请求返回原凭据，不暗示新增积分或奖品 |

名单 `players[].collected`、`receipt` 和 `collectionCount` 都属于当前房间当前宝藏轮次，不是全局资料、终身背包、累计成绩或在线证明。`playerCount` 统计未过期成员，房间码是场次信息，不是公开房间发现列表。尚无离房、删房、修改资料或重置密码接口。

## 定位、相机与生命周期

流程为 `unplaced → leave → return → ready → collected`。按钮启用读取适配器 `snapshot(now)`；缓存的 `ready` 本身不能授权相机或领取。位置分类为 `stopped`、`waiting`、`stale`、`imprecise`、`unplaced`、`inside`、`outside`、`boundary`。

| 状态 / 事件 | 必须保留的行为 |
| --- | --- |
| 无房间 / 非安全来源 | 不申请硬件，说明下一步 |
| `unplaced` | 仅房主且 `snapshot.canPlace` 为真时可放置 |
| `leave` | 解释必须离开，保持相机锁定 |
| `return` | 显示返回 / 稳定位置进度，渲染或定时器不能推进服务端观察 |
| `ready` | 仅 `snapshot.eligible` 为真时提供相机；过期、精度不足、边界或断网均阻止开启 |
| 相机权限 / 等待视频流 | 仅用户点击后申请；取消或后台后才到达的视频流须停止全部 track |
| 视频可用 | 仅有 stream 或权限不够，须观察到帧更新 / 播放时间推进后，宝箱才能领取 |
| 领取 | 同时要求新鲜位置、资格和实时帧，再等待 `collect()` 成功；确认后释放相机 |
| 拒绝权限 / 播放受阻 | 显示可操作的英文重试提示，必要时保留 Resume video |
| 位置过期 / 不再有效 | 关闭相机，禁用领取 |
| 后台 / pagehide / 组件卸载 / 换身份 | 清定位 watch，包括 ID `0`；取消帧回调，停止媒体 track，调用 `session.stop(now)` |
| 前台 / 恢复页面 | 显示暂停，用户再次操作后才重启定位 / 相机 |

当前默认半径 30 m（可设 15–100）、报告精度不超过 20 m、退出缓冲 10 m、位置最长 15 s、返回观察至少 2 s 且使用不同时间戳。均为待现场验证的实验参数，视觉交接期间保留。相机只是叠加展示，不是世界锚定 AR；客户端定位与 `cameraLive` 不是防作弊证据。
